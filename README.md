# FOMO Terminal

Локальный терминал для сделок с нескольких Solana-кошельков через Fomo.
Открывается на http://127.0.0.1:8787, вход с любым паролем.

## Запуск

```sh
./start.sh
```

При первом запуске поставятся зависимости (`npm install`). Нужен Node.js 18+.

## Настройка

Всё в `accounts.config.json` (хранить только локально, в git не попадает):

| Поле | Что это |
|---|---|
| `rpcUrl` | ваш Solana RPC (балансы, подтверждение сделок) |
| `agentToken` | секрет для агента, любая строка от 16 символов |
| `maxUsdPerTrade` | потолок покупки на один кошелёк, USDC |
| `maxParallel` | сколько кошельков торгуют одновременно |
| `jitterMs` | случайная задержка между кошельками, мс |
| `accounts` | кошельки: `name`, `secret`, `group` |

Кошельки можно добавлять и удалять прямо в интерфейсе.

## Агент

В каждом профиле браузера с открытым fomo.family должны стоять два юзерскрипта из папки `inpage/`:
`fomo-trade.user.js` и `fomo-agent.user.js`. При первом запуске агент спросит имя аккаунта
(как в конфиге, например `acc1`) и `agentToken`. Зелёная точка у кошелька в терминале значит, что агент на связи.

## Возможности

- Buy/Sell сразу на выбранных кошельках, группы кошельков.
- Баланс, PnL, Win rate, supply каждой сделки, данные токена (Dexscreener).
- Автоматизации (макс. 2): Buy по расписанию на случайную сумму, Sell при росте цены. Работают на сервере.
- Журнал сделок: `data/journal.jsonl`.

## Если сделка не прошла

Причина видна в ленте транзакций.

- «агент не на связи»: открой fomo.family в профиле и проверь скрипт агента.
- «подпись плательщика Fomo не сходится»: Fomo изменил формат транзакции, нужна правка `src/sign.js`.
- 430 от Fomo: нужен обычный браузер и домашний IP.
- Ошибки RPC: проверь `rpcUrl` и лимиты провайдера.

## Безопасность

Приватные ключи лежат только в `accounts.config.json` и не уходят в браузер.
Не отправляй этот файл и папку целиком в чаты и не выкладывай в git.
